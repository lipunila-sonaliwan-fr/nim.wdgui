# Règles de vie

Le code du cadenas de l'abri est **2468**. Merci de le refermer en partant.

Ne jamais utiliser de produits chimiques dans le jardin. {.alerte}

1. On partage les outils et on les nettoie après usage.
2. On respecte les bacs des autres adhérents.
3. Les enfants sont les bienvenus, accompagnés.
4. Les déchets verts vont au [[Compost]], le reste à la poubelle.

Le non-respect répété de ces règles peut entraîner la perte du bac.
